🔑 API Credentials — Connect Your Accounts
Your keys are stored only in your browser (localStorage). Never sent anywhere except the platform's own API.
Get keys at developer.x.com → Your App → Keys & Tokens. You need OAuth 1.0a User Auth with Read+Write permissions.
Get your token at developers.facebook.com → Tools → Graph API Explorer. Select your Page. Generate token with pages_manage_posts, instagram_basic, instagram_content_publish scopes.
Get token at linkedin.com/developers → Your App → Auth → OAuth 2.0 tools. Need w_member_social scope. Token lasts 60 days.
YouTube requires OAuth 2.0 flow with a registered app and server-side redirect. Use the YouTube Data API v3 via Google Cloud Console. Paste your access token below after completing OAuth flow.
